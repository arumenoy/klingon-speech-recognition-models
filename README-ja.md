# クリンゴン語音声認識AI — 学習済みモデル公開

**話されたクリンゴン語を、端末内でクリンゴン語の文字へ。**

[English](README.md) · [モデルをダウンロード](https://github.com/arumenoy/klingon-speech-recognition-models/releases/latest) · [モデルの説明・検証範囲](MODEL_CARD.md) · [入出力仕様](INFERENCE.md) · [利用条件](LICENSE.md)

「クリンゴン語をスマホに聞き取らせたい」。そんな発想から育てた音声認識モデルを公開します。開発者やクリンゴン語の愛好家が、自分の用途でも試せるようにするためのモデル配布です。

固定されたフレーズ一覧から答えを選ぶ方式ではなく、音声からクリンゴン語の文字列を推定します。推論時に正解文やヒントを与える必要はありません。LLMや音声合成モデルではなく、音声認識用の学習済みモデルです。

## 入手方法

**[Releases](https://github.com/arumenoy/klingon-speech-recognition-models/releases/latest)** から `klingon-asr-models-v1.0.0.zip` と `SHA256SUMS.txt` を取得してください。SHA-256を照合してから展開します。

配布物は5つのONNXモデル、語彙・設定、補助辞書データ、説明書とライセンスです。モデル5個の合計は圧縮前 **376,791,520 bytes（約377MB）**。ひとこと異星人語の更新版1.3.2に組み込んだモデルと同一のものです。

**公開するのはモデル関連のファイルだけです。** 翻訳アプリ本体のソース、学習プログラム、マイク画面、翻訳・読み上げモデル、学習元の録音、署名鍵は公開物に含みません。

## 使い方

入力は16kHz・モノラル音声を想定しています。SenseVoiceSmall由来の音響特徴とZIPA Largeの音素情報を組み合わせ、クリンゴン語用に学習した読取りモデルで文字を推定します。文字言語モデルと辞書は候補の選択を助けます。

これは開発者向けのモデル一式です。ファイルを単体で開くだけで録音から文字が返るアプリではありません。音響特徴の計算、時間方向の位置合わせ、文字への復号を **[INFERENCE.md](INFERENCE.md)** に記載しています。各モデルの入出力・ハッシュは **[model-manifest.json](model-manifest.json)**、設定と文字の対応は `inference-config.json` と `tokens.json` を参照してください。

元のアプリではAndroid上でオフライン動作させています。モデルの取得後、推論にクラウド接続は必要ありません。

## 認識について

人の録音と合成発音を用いて学習したモデルです。話者・発音・録音環境・文によって精度が変わり、別の単語や文になることがあります。クリンゴン語では大文字・小文字やアポストロフィにも意味があります。

検証済みの範囲は **[MODEL_CARD.md](MODEL_CARD.md)** にまとめています。アプリの検査には辞書等の補助処理が含まれます。また、学習に使った声の再認識と、別録音・合成声の検査は分けて記載しています。公開モデルを組み込んだ別の実装で同じ数値が出ることや、あらゆる人の発話を正しく認識することを保証するものではありません。
